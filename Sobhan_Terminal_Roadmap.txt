# نقشه راه پروژه Sobhan Terminal (نسخه ۲.۰ - فاز دسکتاپ و سرویس پایدار)

## خلاصه‌ی وضعیت فعلی
- فازهای A تا H با موفقیت کامل و بیلد سبز تثبیت شدند.
- ماژول KernelSU با قابلیت مانت خودکار در بوت (`service.sh`)، سازگاری نصاب (`customize.sh`) و پکیج زیپ ایجاد شد.
- فاز جاری: فاز I - آماده‌سازی زیرساخت دسکتاپ گرافیکی (X11 / VNC Server در اوبونتو).

---

## وضعیت فازهای قبلی (تکمیل شده)
- [x] فاز A: تنظیم پایه‌ای بیلد و پیکربندی ARM64 فلاتر.
- [x] فاز B: برقراری زنجیره Flutter -> KernelSU -> chroot -> Bash.
- [x] فاز C: رفع موانع چروت اندروید (جایگزینی userspec با su کاربر) و مدیریت سشن.
- [x] فاز D: ترمینال MVP تعاملی، کیبورد اختصاصی و پشتیبانی ANSI.
- [x] فاز E: سخت‌سازی، مانت‌های پایدار proc/sys/dev/pts و تنظیم DNS.
- [x] فاز F: بیلد نهایی کلاینت CLI و پایداری روی دستگاه واقعی.
- [x] فاز G: پایداری پس‌زمینه و ضد-کیل (Foreground Service + معافیت باتری + ضد Phantom Process Killer).
- [x] فاز H: راه‌انداز خودکار سیستمی (ماژول KernelSU شامل module.prop, service.sh, customize.sh و zip نهایی).
